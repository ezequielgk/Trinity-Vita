# Launcher

Trinity Projects baut Launcher, die Spiele ohne native Linux-Unterstützung auf den Linux-Desktop bringen.

Jeder Launcher wird als **Flatpak**-Paket verteilt und bleibt so vom Kernsystem isoliert – für eine sichere und stabile Erfahrung.

## Verfügbare Launcher

### Minecraft Bedrock
Spiele **Minecraft Bedrock Edition** unter Linux mit einer nativen Erfahrung, unterstützt durch die Community-Projekte `mcpelauncher` und `msa`.
