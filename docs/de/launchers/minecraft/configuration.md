# Trinity Launcher Konfiguration
Konfiguriere Trinity Launcher für ein optimales Minecraft-Bedrock-Erlebnis

## 1. Ersteinrichtung
**Füge deine erste Minecraft-Version hinzu**

Um Trinity Launcher zu nutzen, musst du mindestens eine Minecraft-Bedrock-Version im APK-Format importieren.

### APK-Anforderungen
* **Architektur:** `x86_64` (64-Bit)
* **Format:** `.apk`-Datei
* **Kompatibilität:** Jede Bedrock-Version

::: danger Wichtig
**Trinity Launcher stellt KEINE Kopien von Minecraft Bedrock bereit.** Du musst deine eigene Kopie auf legalem Weg erwerben.
:::

## 2. Versionsverwaltung
**Mehrere Instanzen verwalten**

Trinity Launcher ermöglicht die gleichzeitige Verwaltung mehrerer Minecraft-Bedrock-Versionen.

**Verschiedene Erlebnisse**
* Stabile Version für normales Spielen
* Beta-Version für neue Funktionen
* Ältere Versionen für Mod-Kompatibilität

**Spezifische Konfigurationen**
* Profile mit unterschiedlichen Mod-Sets
* Optimierte Leistungseinstellungen
* Getrennte Welten pro Version

::: tip 💡 Tipp
Um eine neue Version hinzuzufügen, wähle **"APK extrahieren"** in der Trinity-Launcher-Oberfläche und wähle deine heruntergeladene Datei.
:::

## 3. Anpassung und Inhalte
**Mods, Packs und Welten**

Verwalte alle deine Inhalte direkt über die Launcher-Oberfläche.

**Texturpakete**
* Unterstützt `.mcpack`
* Live-Vorschau
* Einfache Verwaltung

**Mods & Addons**
* Unterstützt `.mcaddon`
* Abhängigkeitsverwaltung
* Installation mit einem Klick

**Welten**
* `.mcworld` importieren
* Backup-System
* Einfaches Teilen
