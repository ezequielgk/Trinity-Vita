# Ласкаво просимо до Trinity

Trinity — це екосистема Linux-проєктів з відкритим вихідним кодом: ігровий лаунчер, легкий дистрибутив Void Linux та багато іншого.

## Проєкти

- **Trinity Launcher:** Керує вашою грою, екземплярами та акаунтами. Створений на Qt6 і поширюється через Flatpak.
- **Neko Void:** Дистрибутив **Void Linux** з `runit`, робочим столом MATE та попередньо налаштованою підтримкою ігор. На 100% без systemd.
- **CMUS++:** Термінальний музичний плеєр.
- **Audio Source:** Використовуйте пристрій Android як USB-мікрофон.
- **BedrockOnLinux:** Запускайте Minecraft Bedrock для Windows (видання GDK) у Linux із нативним акаунтом Microsoft/Xbox.
- **GenovaLauncher:** Сучасний графічний лаунчер для Minecraft: Bedrock Edition у Linux.
