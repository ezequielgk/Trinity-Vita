# Керування екземплярами та контентом

Trinity Launcher складається з двох основних застосунків, які охоплюють різні аспекти роботи з Minecraft Bedrock.

## Trinchete
**Інтерфейс лаунчера**

Основний застосунок для керування версіями, запуску гри та налаштування екземплярів.

### Можливості верхньої панелі
*   **Видобути APK:** Вибирає файл `.apk`, задає власну назву та видобуває його за допомогою `mcpelauncher-extract`.
*   **Імпорт:** Відновлює збережену версію з архіву `.tar.gz`.
*   **Інструменти:** Швидко відкриває застосунок **Trinito**.

### Можливості правої панелі
*   **PLAY:** Запускає вибрану версію за допомогою `mcpelauncher-client`.
*   **Створити ярлик:** Створює файл `.desktop` для швидкого доступу з системного меню.
*   **Змінити конфігурацію:** Дозволяє додавати змінні середовища (наприклад, `DRI_PRIME=1`) для конкретних конфігурацій запуску.
*   **Експорт:** Створює резервну копію поточної версії у файл `.tar.gz`.
*   **Видалити:** Назавжди видаляє вибрану версію та її дані.

## Trinito
**Менеджер контенту**

Спеціалізований інструмент для керування модами, пакетами текстур і світами без прямого доступу до файлової системи.

### Вкладки контенту

| Вкладка | Тип | Папка призначення |
| :--- | :--- | :--- |
| **Моди** | Файл | `behavior_packs/` |
| **Текстури** | Файл | `resource_packs/` |
| **Світи** | Папка | `minecraftWorlds/` |

### Стани
*   **Увімкнено:** Файл зберігає свою звичайну назву та завантажується грою.
*   **Вимкнено:** Файл перейменовується з розширенням `.disabled` та ігнорується грою.
*   **Інтерактивний:** Використовуйте прапорці, щоб миттєво вмикати або вимикати контент.
