# Модульна архітектура

Trinity Launcher дотримується чистої архітектури на основі окремих бібліотек, щоб забезпечити модульність і зручність супроводу.

## Структура

### ▸ TrinityCore
Інкапсулює всю **бізнес-логіку**.
-   Керування версіями
-   Обробка паків
-   Логіка запуску
-   Операції експорту/імпорту

### ▸ TrinityUI
Містить **графічні інтерфейси**.
-   Вікна
-   Діалоги
-   Віджети
-   Компоненти представлення

Такий поділ дозволяє тестувати основну логіку незалежно від UI і потенційно перевикористовувати її в інших інтерфейсах (наприклад, CLI).
