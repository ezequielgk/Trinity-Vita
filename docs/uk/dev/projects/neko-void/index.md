**Дистрибутив Void Linux для швидких, ігрових і вільних від systemd робочих столів**

Neko Void — дистрибутив Linux на основі **Void Linux** з `runit` для надшвидкого завантаження. Він включає середовище робочого столу **MATE** з попередньо встановленими необхідними інструментами, оптимізований для ігор і готовий до щоденного використання одразу після встановлення.

## Базова архітектура

Заснований на Void Linux з `runit`, включно з робочим столом MATE з попередньо встановленими необхідними інструментами:

* **Flatpak** Універсальні пакети
* **Kore** Менеджер tarball і AppImage
* **Tinyfetch** Інформація про систему
* **btop** Монітор ресурсів
* **Octoxbps** Менеджер пакетів із графічним інтерфейсом

## Готовність до ігор

Оптимізований для максимальної продуктивності з повною підтримкою Vulkan і попередньо налаштованими невільними драйверами Intel/AMD для безпроблемної гри з першого дня.

* Повна підтримка API **Vulkan**
* Попередньо налаштовані драйвери GPU
* Оптимізовані налаштування продуктивності
* Готовий до роботи з **Steam** і **Lutris**

## Інсталятор Kasha

Користувацький інсталятор, який спрощує налаштування Void Linux. Включає потужного помічника після встановлення для налаштування спеціалізованих робочих процесів в один клік.

* Просте налаштування користувача та мережі
* Автоматичне розбиття диска
* Категорії застосунків в один клік
* Відео, музика, дизайн, ігри тощо

## Філософія

### Чому він був створений

Проєкт почався як особисте хобі. З часом він перетворився на структурований проєкт із метою запропонувати версію Void Linux, яку легко встановити та використовувати кінцевому користувачеві.

### Цільова аудиторія

Цей дистрибутив призначений для користувачів, які хочуть легку та надійну операційну систему, легко адаптовану до їхнього конкретного робочого процесу, без звичайних складнощів ручного налаштування з нуля.

### Простота замість складності

Зосередження надто великої влади в єдиному наборі на кшталт systemd суперечить ідеї UNIX про маленькі окремі інструменти. Ми віримо, що робити одну річ добре — ключ до стабільної системи.

### Прозорість і контроль

Монолітний набір збільшує поверхню атаки та додає непотрібну абстракцію. Ми віддаємо перевагу текстовим журналам заради простоти та переносимості. Якщо щось виходить з ладу, читати текстові файли стандартними інструментами на кшталт `cat`, `less` чи `grep` набагато простіше, ніж покладатися на бінарні журнали.

### На 100% без systemd

Ми з гордістю підтримуємо ініціативу [systemdfree.com](https://systemdfree.com/). Використовуючи `runit`, ми гарантуємо, що ваша система залишається модульною, прозорою та вільною від монолітних залежностей.
