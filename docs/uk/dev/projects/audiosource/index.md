# Audio Source
**Використовуйте пристрій Android як USB-мікрофон**

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Android_Linux-9cf.svg)

[Відвідати репозиторій](https://github.com/ezequielgk/audiosource)

> [!NOTE]
> Це форк, який додає **термінальний інтерфейс користувача (TUI)** та **значок системного трея** для простішого керування застосунком. Він працює безпосередньо з офіційним APK від оригінального автора, [gdzx](https://github.com/gdzx/audiosource), без необхідності встановлювати кастомний чи модифікований APK.

Audio Source пересилає звук із мікрофона Android у **демон PulseAudio** через ADB, тому ви можете використовувати пристрій Android як USB-мікрофон.

## Вимоги

- Пристрій щонайменше з **Android 4.0** (API level 14), але повністю протестовано лише на Android 10 (API level 29), тому результат може відрізнятися.
- **Android SDK Platform Tools** (потрібен `adb` у PATH).
- **PulseAudio або PipeWire** з підтримкою PulseAudio (потрібен `pactl` у PATH).

## Встановлення

### На пристрої Android

1. Перейдіть у **Налаштування > Про телефон** і натисніть на **Номер збірки** 7 разів, щоб увімкнути меню **Параметри розробника**.
2. У **Налаштуваннях > Система > Параметри розробника** увімкніть **налагодження USB** (Android Debug Bridge).
3. Встановіть застосунок Audio Source:
   - (Рекомендовано) Візьміть його на [F-Droid](https://f-droid.org/).
   - Або завантажте APK з останнього релізу.
   - Або зберіть із вихідного коду (див. «Збірка та встановлення»).

### На вашому ПК з Linux

#### Автоматичне встановлення (рекомендовано)

Ви можете завантажити, розпакувати та запустити інтерактивний інсталятор однією командою:

```sh
curl -sSL https://raw.githubusercontent.com/ezequielgk/audiosource/master/install.sh | bash
```

**Для Void:**

```sh
curl -sSL https://raw.githubusercontent.com/ezequielgk/audiosource/master/install-void.sh | bash
```

#### Ручне встановлення

1. Завантажте клієнт `audiosource-linux.tar.gz` для Linux з останнього релізу.
2. Розпакуйте архів і відкрийте термінал у розпакованому каталозі.
3. Запустіть інтерактивний інсталятор:

```sh
$ ./install.sh
```

Інсталятор пропонує меню для вирішення залежностей (потрібен sudo), локального встановлення застосунку або його видалення.

## Використання

### TUI на робочому столі та системний трей

Після встановлення ви можете запустити застосунок із меню застосунків робочого столу (знайдіть **Audio Source**) або безпосередньо з будь-якого терміналу:

```sh
$ audiosource
```

Це автоматично запускає значок системного трея та підключає до нього термінальний інтерфейс.

### Інтерактивне керування

| Клавіша | Дія |
| --- | --- |
| **[S]** | Старт: запускає пересилання звуку. |
| **[C]** | Стоп: зупиняє пересилання звуку. |
| **[T]** | Згорнути в трей: закриває термінальний інтерфейс, але залишає демон системного трея та пересилання звуку працювати у фоновому режимі (нативно інтегрується зі сповіщеннями робочого столу). |
| **[M]** | Заглушити/Увімкнути: миттєво перемикає вимкнення мікрофона. |
| **[Z]/[X]** | Гучність: динамічне регулювання гучності мікрофона з миттєвим візуальним зворотним зв'язком. |
| **[W]** | Web: запускає локальний вебсервер для керування звуком і перегляду QR-коду (з прямою URL-адресою). Підключатися можна з будь-якого пристрою у вашій мережі. |
| **[A]** | ADB: відкриває меню бездротового налагодження для сполучення або підключення пристрою через Wi-Fi, включно з новою опцією сполучення через QR. |
| **[Q]** | Вийти з усього: закриває термінальний інтерфейс, завершує демон системного трея та зупиняє пересилання звуку. |

### Бездротове налагодження (Wi-Fi)

Ви можете використовувати Audio Source без USB-кабелю, підключаючись через Wi-Fi нативно через інтерфейс. Натисніть **[A] ADB** у TUI, щоб відкрити бездротове меню:

- **Connect:** Використовуйте для підключення до вже сполученого пристрою, ввівши його IP і порт.
- **Pair (Android 11+):** Введіть IP сполучення, порт і 6-значний код сполучення, який показує ваш телефон у параметрах розробника.
- **Pair via QR (Android 11+):** TUI піднімає нативний mDNS-сервер і показує QR-код на екрані. Просто відскануйте його на екрані телефону **«Бездротове налагодження -> Сполучення пристрою за QR-кодом»**!

> [!NOTE]
> Аудіопотік автоматично буферизується та оптимізується для Wi-Fi, щоб запобігти обривам звуку та з'єднання.

### Інтерфейс командного рядка (CLI)

Встановлена команда `audiosource` також підтримує спеціальні аргументи:

- **Оновити застосунок:** автоматично завантажує та встановлює останню версію з GitHub:

```sh
$ audiosource update
```

- **Допомога:** показати доступні параметри командного рядка:

```sh
$ audiosource --help
```

- **Версія:** показати поточну версію застосунку:

```sh
$ audiosource --version
```

### Користувацьке ASCII-мистецтво

Ви можете персоналізувати логотип TUI, замінивши стандартну графіку:

- Відредагуйте файл `~/.config/audiosource/ascii.txt` і вставте свій текст. TUI автоматично відцентрує його та безшовно підлаштує макет.
- Або використовуйте `~/.config/audiosource/config.json` з ключем `ascii_art`.

### Кілька пристроїв

Якщо у вас підключено кілька пристроїв, вам потрібно вказати серійний номер пристрою, на який ви хочете пересилати звук. Серійні номери пристроїв можна дізнатися, виконавши `adb devices`.

Потім ви можете вказати серійний номер як аргумент:

```sh
$ ./audiosource -s 1234 run
```

Або встановивши змінну середовища `ANDROID_SERIAL`:

```sh
$ ANDROID_SERIAL=1234 ./audiosource run
```

Ви можете використовувати керування завданнями для пересилання звуку з кількох пристроїв одночасно:

```sh
$ ./audiosource -s shiba run &  # натисніть ENTER, щоб повернути контроль над терміналом
$ ./audiosource -s 192.168.1.188:39857 run
```

## Усунення неполадок

Якщо ви стикаєтеся з помилкою **adb not found**, це означає, що команда `adb` або не встановлена, або не знаходиться в PATH вашої системи. У більшості дистрибутивів її можна встановити через менеджер пакетів:

```sh
# Arch Linux
$ pacman -S android-tools

# Debian/Ubuntu
$ apt install android-tools-adb
```

Після встановлення перевірте працездатність командою `adb --version` і знову запустіть `audiosource`.

**Часті поради:**

- Переконайтеся, що телефон підключено, налагодження USB увімкнено, а ПК авторизовано (перевірте телефон на запит дозволу з'єднання).
- Виконайте `adb devices`, щоб переконатися, що телефон виявлено (має показуватися серійний номер і «device»).
- Якщо пристрої не знайдено, спробуйте інший USB-кабель/порт або ввімкніть налагодження USB заново.

## Збірка та встановлення

Виконайте `./gradlew tasks`, щоб отримати список доступних команд.

### Debug

```sh
$ ./audiosource build
$ ./audiosource install
```

### Release

1. Створіть Java KeyStore:

```sh
$ keytool -keystore /home/user/android.jks -genkey -alias release \
       -keyalg RSA -keysize 2048 -validity 30000
```

2. Створіть файл `keystore.properties` у кореневому каталозі проєкту з таким вмістом:

```properties
storeFile=/home/user/android.jks
storePassword=STORE_PASS
keyAlias=release
keyPassword=KEY_PASS
```

3. Зберіть і встановіть:

```sh
$ export AUDIOSOURCE_PROFILE=release
$ ./audiosource build
$ ./audiosource install
```
