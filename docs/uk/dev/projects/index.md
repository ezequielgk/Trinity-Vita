# Проєкти

Дізнайтеся про архітектуру та технічні деталі екосистеми Trinity Projects.

## Trinity Launcher

Сучасне модульне графічне середовище для запуску та керування **Minecraft Bedrock Edition** на Linux.

- [Домашня сторінка проєкту](./trinity-launcher/index.md)
- [Модульна архітектура](./trinity-launcher/architecture.md)
- [Керування екземплярами та контентом](./trinity-launcher/instance-management.md)
- [Компіляція та встановлення](./trinity-launcher/build-process.md)

## Neko Void

Дистрибутив **Void Linux** з `runit`, робочим столом MATE та попередньо налаштованою підтримкою ігор — на 100% без systemd.

- [Домашня сторінка проєкту](./neko-void/index.md)

## CMUS++

Надлегкий термінальний музичний плеєр із керуванням з клавіатури, написаний на C++17.

- [Домашня сторінка проєкту](./cmuspp/index.md)

## Audio Source

Використовуйте пристрій Android як USB-мікрофон із керуванням через TUI та системний трей.

- [Домашня сторінка проєкту](./audiosource/index.md)

## BedrockOnLinux

Запускайте Minecraft Bedrock для Windows (видання GDK) у Linux із нативним акаунтом Microsoft/Xbox.

- [Домашня сторінка проєкту](./bedrock-on-linux/index.md)

## GenovaLauncher

Сучасний графічний лаунчер для Minecraft: Bedrock Edition у Linux, побудований на PySide6 (Qt6).

- [Домашня сторінка проєкту](./genova-launcher/index.md)
