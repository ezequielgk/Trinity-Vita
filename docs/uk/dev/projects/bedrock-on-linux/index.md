# BedrockOnLinux
**Запускайте Minecraft Bedrock для Windows (видання GDK) у Linux із нативним акаунтом Microsoft/Xbox**

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Linux-9cf.svg)

[Відвідати репозиторій](https://github.com/Wyze3306/BedrockOnLinux)

BedrockOnLinux встановлює вибрану вами версію Minecraft, готує керований Wine-префікс і запускає гру через перевірений рушій **GDK-Proton на основі WineGDK**. Компілятор або встановлення Windows не потрібні.

## Можливості

- **Нативний акаунт Xbox:** конфігурація XGame, XUser, сигнатури запитів, геймертеги, привілеї та контекст XSAPI реалізовані у WineGDK.
- **Гра онлайн:** список друзів, запрошення, публічні сервери та Realms використовують цей нативний акаунт. Realms отримує окремий XSTS-токен для аудиторії Bedrock Realms.
- **Без патчера пам'яті Minecraft:** керований рушій не містить коду, який сканує або переписує запущений процес Minecraft.
- **Нативний вибір файлів:** імпорт світів у грі та вибір власного скіна відкривають діалог вибору файлів робочого столу.
- **Безпека графіки:** відома небезпечна сесія блокується до запуску Wine.
- **Перевірені оновлення:** архіви рушія, файли середовища виконання та корисні навантаження залежностей прив'язані до SHA-256.
- **Ізольовані профілі акаунтів:** один користувач Linux може створити окремі корені для акаунта Xbox, Wine-префікса, налаштувань і світів.

Процес входу Microsoft відбувається локально. BedrockOnLinux не використовує ретранслятор акаунтів або мультиплеєрний проксі.

## Формати встановлення

| Формат | Для кого | Команда запуску |
| --- | --- | --- |
| AppImage | Більшість дистрибутивів на основі glibc | `./BedrockOnLinux-*-x86_64.AppImage` |
| .deb | Debian, Ubuntu, Mint і LMDE | `sudo apt install ./bedrock-on-linux_*_amd64.deb` |
| Переносний .pyz | Система з Python 3.9+ та Tk | `./bedrock-on-linux-*.pyz gui` |
| Flatpak-пакет | Ізольована локальна установка, коли доступний | `flatpak install --user ./BedrockOnLinux-*-x86_64.flatpak` |
