# Лаунчери

Trinity Projects створює лаунчери, які приносять ігри без нативної підтримки Linux на робочий стіл Linux.

Кожен лаунчер поширюється як пакет **Flatpak**, залишаючись ізольованим від вашої основної системи для безпечного та стабільного використання.

## Доступні лаунчери

### Minecraft Bedrock
Грайте в **Minecraft Bedrock Edition** на Linux із майже нативним досвідом завдяки проєктам спільноти `mcpelauncher` та `msa`.

- [Огляд](./minecraft/overview) Як це працює
- [Встановлення](./minecraft/installation) Встановлення лаунчера
- [Конфігурація](./minecraft/configuration) Налаштування версій і контенту
