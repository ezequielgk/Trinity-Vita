# Лаунчери

Trinity Projects створює лаунчери, які приносять ігри без нативної підтримки Linux на робочий стіл Linux.

Кожен лаунчер поширюється як пакет **Flatpak**, залишаючись ізольованим від вашої основної системи для безпечного та стабільного використання.

## Доступні лаунчери

### Trinity Launcher
Грайте в **Minecraft Bedrock Edition** на Linux із майже нативним досвідом завдяки проєктам спільноти `mcpelauncher` та `msa`.

- [Огляд](./minecraft/overview) Як це працює
- [Встановлення](./minecraft/installation) Встановлення лаунчера
- [Конфігурація](./minecraft/configuration) Налаштування версій і контенту

### BedrockOnLinux
Запускайте **Minecraft Bedrock для Windows (видання GDK)** у Linux із нативним акаунтом Microsoft/Xbox: мультиплеєр, друзі та Realms.

- [Огляд](./bedrock-on-linux/) Запуск видання GDK для Windows із нативним акаунтом Xbox
- [Встановлення](./bedrock-on-linux/#встановлення) AppImage, .deb, .pyz і Flatpak

### GenovaLauncher
Сучасний графічний лаунчер для **Minecraft: Bedrock Edition** у Linux, побудований на PySide6 (Qt6) і заснований на mcpelauncher.

- [Огляд](./genova-launcher/) Сучасний лаунчер на PySide6 для Bedrock Edition
