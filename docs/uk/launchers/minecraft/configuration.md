# Конфігурація Trinity Launcher
Налаштуйте Trinity Launcher для оптимального досвіду Minecraft Bedrock

## 1. Початкове налаштування
**Додайте свою першу версію Minecraft**

Щоб почати використовувати Trinity Launcher, вам потрібно імпортувати щонайменше одну версію Minecraft Bedrock у форматі APK.

### Вимоги до APK
* **Архітектура:** `x86_64` (64-біт)
* **Формат:** файл `.apk`
* **Сумісність:** будь-яка версія Bedrock

::: danger Важливо
**Trinity Launcher НЕ надає копії Minecraft Bedrock.** Ви повинні отримати власну копію законним способом.
:::

## 2. Керування версіями
**Керування кількома екземплярами**

Trinity Launcher дозволяє керувати кількома версіями Minecraft Bedrock одночасно.

**Різні варіанти досвіду**
* Стабільна версія для звичайної гри
* Бета-версія для нових функцій
* Старі версії для сумісності з модами

**Конкретні конфігурації**
* Профілі з різними наборами модів
* Оптимізовані налаштування продуктивності
* Окремі світи для кожної версії

::: tip 💡 Порада
Щоб додати нову версію, виберіть **«Видобути APK»** в інтерфейсі Trinity Launcher і вкажіть завантажений файл.
:::

## 3. Налаштування та контент
**Моди, паки та світи**

Керуйте усім своїм контентом прямо з інтерфейсу лаунчера.

**Пакети текстур**
* Підтримка `.mcpack`
* Живий попередній перегляд
* Легке керування

**Моди та аддони**
* Підтримка `.mcaddon`
* Обробка залежностей
* Встановлення в один клік

**Світи**
* Імпорт `.mcworld`
* Система резервного копіювання
* Легкий обмін
