# Журнали та звіти

Коли виникає проблема з Trinity Launcher або будь-яким із його компонентів, надання детального звіту з журналами є надзвичайно важливим, щоб наша команда могла ефективно вам допомогти.

## 1. Отримання журналів лаунчера

Перш ніж скласти звіт, вам потрібно отримати журнали, які містять технічні деталі про помилку.

### Як експортувати журнали через термінал

Наразі найнадійніший спосіб отримати журнали — запустити застосунок із терміналу. Це захоплює вивід у реальному часі, що критично важливо для налагодження.

**Для користувачів Flatpak:**
```bash
flatpak run "Package.ID"
```

**Для користувачів Native / AppImage:**
```bash
# AppImage
./TrinityLauncher.AppImage

# Native
trinity-launcher
```

Скопіюйте вивід терміналу та збережіть його у текстовий файл з ім'ям `trinity-log.txt`.

## 2. Повідомлення про проблему

Отримавши журнали, виконайте наведені нижче кроки, щоб правильно повідомити про проблему.

1.  Приєднайтеся до нашого **Discord-сервера**.
2.  Перейдіть у канал **#help-forum**.
3.  **Створіть нову тему** для своєї проблеми.

## 3. Що включити у звіт

Ваша тема має містити наведені нижче деталі, щоб її розглянули. **Поясніть чітко:**

*   **Що сталося:** Чіткий опис помилки.
*   **Як це сталося:** Покрокова інструкція з відтворення проблеми.
*   **Деталі системи:**
    *   ОС і версія (наприклад, Ubuntu 22.04, Arch Linux).
    *   Версія лаунчера.
    *   Компоненти/обладнання (CPU, GPU, RAM) — *Повідомляйте лише актуальну інформацію.*
*   **Вжиті дії:** Що ви вже пробували зробити для виправлення?

## 4. Рекомендації

::: warning ВАЖЛИВО
**Дотримуйтеся закріплених повідомлень у каналі #help-forum.**
:::

Недотримання рекомендацій або надання неповної інформації може призвести до того, що ваш запит у підтримку буде проігноровано або закрито. 

*   Будьте терплячими та ввічливими.
*   Не надсилайте особисті повідомлення членам команди для отримання підтримки.
*   Використовуйте блоки коду для коротких фрагментів журналів або завантажуйте файл для довгих журналів.
