# BedrockOnLinux
**Запускайте Minecraft Bedrock для Windows (издание GDK) в Linux с нативной учётной записью Microsoft/Xbox**

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Linux-9cf.svg)

[Посетить репозиторий](https://github.com/Wyze3306/BedrockOnLinux)

BedrockOnLinux устанавливает выбранную вами версию Minecraft, подготавливает управляемый Wine-prefix и запускает игру через проверенный движок GDK-Proton на основе WineGDK. Ни компилятор, ни установка Windows не требуются.

## Ключевые возможности

- **Нативная учётная запись Xbox:** конфигурация XGame, XUser, подписи запросов, геймертеги, привилегии и контекст XSAPI реализуются WineGDK.
- **Игра по сети:** список друзей, приглашения, публичные серверы и Realms используют эту нативную учётную запись. Realms получает выделенный токен XSTS для аудитории Bedrock Realms.
- **Без патча памяти Minecraft:** управляемый движок не содержит кода, который сканирует или переписывает запущенный процесс Minecraft.
- **Нативный выбор файлов:** импорт миров и выбор пользовательских скинов в игре открывают диалог рабочего стола.
- **Безопасность графики:** известная небезопасная сессия блокируется до запуска Wine.
- **Проверенные обновления:** архивы движка, файлы среды выполнения и зависимые полезные нагрузки привязаны к SHA-256.
- **Изолированные профили учётных записей:** один пользователь Linux может создавать отдельные корни для учётной записи Xbox, Wine-prefix, настроек и миров.

Поток входа в Microsoft выполняется локально. BedrockOnLinux не использует ретранслятор учётных записей или мультиплеерный прокси.

## Форматы установки

| Формат | Для чего лучше | Команда запуска |
| --- | --- | --- |
| AppImage | Большинство дистрибутивов на базе glibc | `./BedrockOnLinux-*-x86_64.AppImage` |
| .deb | Debian, Ubuntu, Mint и LMDE | `sudo apt install ./bedrock-on-linux_*_amd64.deb` |
| Портативный .pyz | Хост с Python 3.9+ и Tk | `./bedrock-on-linux-*.pyz gui` |
| Пакет Flatpak | Изолированная локальная установка, когда доступен | `flatpak install --user ./BedrockOnLinux-*-x86_64.flatpak` |
