# Audio Source
**Используйте устройство Android как USB-микрофон**

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Android_Linux-9cf.svg)

[Посетить репозиторий](https://github.com/ezequielgk/audiosource)

> [!NOTE]
> Это форк, добавляющий **интерфейс командной строки (TUI)** и **значок системного трея** для более простого управления приложением. Он работает напрямую с официальным APK от оригинального автора, [gdzx](https://github.com/gdzx/audiosource), без необходимости устанавливать кастомный или модифицированный APK.

Audio Source пересылает звук с микрофона Android в **демон PulseAudio** через ADB, поэтому вы можете использовать устройство Android как USB-микрофон.

## Требования

- Устройство как минимум с **Android 4.0** (API level 14), но полностью протестировано только на Android 10 (API level 29), поэтому результат может отличаться.
- **Android SDK Platform Tools** (требуется `adb` в PATH).
- **PulseAudio или PipeWire** с поддержкой PulseAudio (требуется `pactl` в PATH).

## Установка

### На устройстве Android

1. Перейдите в **Настройки > О телефоне** и нажмите на **Номер сборки** 7 раз, чтобы включить меню **Параметры разработчика**.
2. В **Настройках > Система > Параметры разработчика** включите **отладку по USB** (Android Debug Bridge).
3. Установите приложение Audio Source:
   - (Рекомендуется) Возьмите его на [F-Droid](https://f-droid.org/).
   - Или скачайте APK из последнего релиза.
   - Или соберите из исходного кода (см. «Сборка и установка»).

### На вашем ПК с Linux

#### Автоматическая установка (рекомендуется)

Вы можете скачать, распаковать и запустить интерактивный установщик одной командой:

```sh
curl -sSL https://raw.githubusercontent.com/ezequielgk/audiosource/master/install.sh | bash
```

**Для Void:**

```sh
curl -sSL https://raw.githubusercontent.com/ezequielgk/audiosource/master/install-void.sh | bash
```

#### Ручная установка

1. Скачайте клиент `audiosource-linux.tar.gz` для Linux из последнего релиза.
2. Распакуйте архив и откройте терминал внутри распакованного каталога.
3. Запустите интерактивный установщик:

```sh
$ ./install.sh
```

Установщик предлагает меню для разрешения зависимостей (требуется sudo), локальной установки приложения или его удаления.

## Использование

### TUI на рабочем столе и системный трей

После установки вы можете запустить приложение из меню приложений рабочего стола (найдите **Audio Source**) или напрямую из любого терминала:

```sh
$ audiosource
```

Это автоматически запускает значок системного трея и подключает к нему терминальный интерфейс.

### Интерактивное управление

| Клавиша | Действие |
| --- | --- |
| **[S]** | Старт: запускает пересылку звука. |
| **[C]** | Стоп: останавливает пересылку звука. |
| **[T]** | Свернуть в трей: закрывает терминальный интерфейс, но оставляет демон системного трея и пересылку звука работать в фоне (нативно интегрируется с уведомлениями рабочего стола). |
| **[M]** | Заглушить/Включить: мгновенно переключает отключение микрофона. |
| **[Z]/[X]** | Громкость: динамическая регулировка громкости микрофона с мгновенной визуальной обратной связью. |
| **[W]** | Web: запускает локальный веб-сервер для управления звуком и просмотра QR-кода (с прямой ссылкой). Подключаться можно с любого устройства в вашей сети. |
| **[A]** | ADB: открывает меню беспроводной отладки для сопряжения или подключения устройства по Wi-Fi, включая новую опцию сопряжения по QR. |
| **[Q]** | Выйти из всего: закрывает терминальный интерфейс, завершает демон системного трея и останавливает пересылку звука. |

### Беспроводная отладка (Wi-Fi)

Вы можете использовать Audio Source без USB-кабеля, подключаясь по Wi-Fi нативно через интерфейс. Нажмите **[A] ADB** в TUI, чтобы открыть беспроводное меню:

- **Connect:** Используйте для подключения к уже сопряжённому устройству, введя его IP и порт.
- **Pair (Android 11+):** Введите IP сопряжения, порт и 6-значный код сопряжения, который показывает ваш телефон в параметрах разработчика.
- **Pair via QR (Android 11+):** TUI поднимает нативный mDNS-сервер и показывает QR-код на экране. Просто отсканируйте его на экране телефона **«Беспроводная отладка -> Сопряжение устройства по QR-коду»**!

> [!NOTE]
> Аудиопоток автоматически буферизуется и оптимизируется для Wi-Fi, чтобы предотвратить обрывы звука и соединения.

### Интерфейс командной строки (CLI)

Установленная команда `audiosource` также поддерживает специальные аргументы:

- **Обновить приложение:** автоматически скачивает и устанавливает последнюю версию с GitHub:

```sh
$ audiosource update
```

- **Помощь:** показать доступные параметры командной строки:

```sh
$ audiosource --help
```

- **Версия:** показать текущую версию приложения:

```sh
$ audiosource --version
```

### Пользовательское ASCII-искусство

Вы можете персонализировать логотип TUI, заменив стандартную графику:

- Отредактируйте файл `~/.config/audiosource/ascii.txt` и вставьте свой текст. TUI автоматически отцентрирует его и бесшовно подстроит макет.
- Либо используйте `~/.config/audiosource/config.json` с ключом `ascii_art`.

### Несколько устройств

Если у вас подключено несколько устройств, вам нужно указать серийный номер устройства, на которое вы хотите пересылать звук. Серийные номера устройств можно узнать, выполнив `adb devices`.

Затем вы можете указать серийный номер как аргумент:

```sh
$ ./audiosource -s 1234 run
```

Или установив переменную окружения `ANDROID_SERIAL`:

```sh
$ ANDROID_SERIAL=1234 ./audiosource run
```

Вы можете использовать управление заданиями для пересылки звука с нескольких устройств одновременно:

```sh
$ ./audiosource -s shiba run &  # нажмите ENTER, чтобы вернуть контроль над терминалом
$ ./audiosource -s 192.168.1.188:39857 run
```

## Устранение неполадок

Если вы столкнулись с ошибкой **adb not found**, это значит, что команда `adb` либо не установлена, либо не находится в PATH вашей системы. В большинстве дистрибутивов её можно установить через менеджер пакетов:

```sh
# Arch Linux
$ pacman -S android-tools

# Debian/Ubuntu
$ apt install android-tools-adb
```

После установки проверьте работоспособность командой `adb --version` и снова запустите `audiosource`.

**Частые советы:**

- Убедитесь, что телефон подключён, отладка по USB включена, а ПК авторизован (проверьте телефон на наличие запроса на разрешение соединения).
- Выполните `adb devices`, чтобы убедиться, что телефон обнаружен (должен показываться серийный номер и «device»).
- Если устройства не найдены, попробуйте другой USB-кабель/порт или включите отладку по USB заново.

## Сборка и установка

Выполните `./gradlew tasks`, чтобы получить список доступных команд.

### Debug

```sh
$ ./audiosource build
$ ./audiosource install
```

### Release

1. Создайте Java KeyStore:

```sh
$ keytool -keystore /home/user/android.jks -genkey -alias release \
       -keyalg RSA -keysize 2048 -validity 30000
```

2. Создайте файл `keystore.properties` в корневом каталоге проекта со следующим содержимым:

```properties
storeFile=/home/user/android.jks
storePassword=STORE_PASS
keyAlias=release
keyPassword=KEY_PASS
```

3. Соберите и установите:

```sh
$ export AUDIOSOURCE_PROFILE=release
$ ./audiosource build
$ ./audiosource install
```
