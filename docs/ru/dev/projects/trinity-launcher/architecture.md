# Модульная архитектура

Trinity Launcher следует чистой архитектуре на основе раздельных библиотек, чтобы обеспечить модульность и удобство сопровождения.

## Структура

### ▸ TrinityCore
Инкапсулирует всю **бизнес-логику**.
-   Управление версиями
-   Обработка паков
-   Логика запуска
-   Операции экспорта/импорта

### ▸ TrinityUI
Содержит **графические интерфейсы**.
-   Окна
-   Диалоги
-   Виджеты
-   Компоненты представления

Такое разделение позволяет тестировать основную логику независимо от UI и потенциально переиспользовать её в других интерфейсах (например, CLI).
