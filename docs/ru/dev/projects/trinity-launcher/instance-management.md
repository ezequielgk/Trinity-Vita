# Управление экземплярами и контентом

Trinity Launcher состоит из двух основных приложений, которые охватывают разные аспекты работы с Minecraft Bedrock.

## Trinchete
**Интерфейс лаунчера**

Основное приложение для управления версиями, запуска игры и настройки экземпляров.

### Возможности верхней панели
*   **Извлечь APK:** Выбирает файл `.apk`, задаёт собственное имя и извлекает его с помощью `mcpelauncher-extract`.
*   **Импорт:** Восстанавливает сохранённую версию из архива `.tar.gz`.
*   **Инструменты:** Быстро открывает приложение **Trinito**.

### Возможности правой панели
*   **PLAY:** Запускает выбранную версию с помощью `mcpelauncher-client`.
*   **Создать ярлык:** Генерирует файл `.desktop` для быстрого доступа из системного меню.
*   **Изменить конфигурацию:** Позволяет добавлять переменные окружения (например, `DRI_PRIME=1`) для конкретных конфигураций запуска.
*   **Экспорт:** Создаёт резервную копию текущей версии в файл `.tar.gz`.
*   **Удалить:** Навсегда удаляет выбранную версию и её данные.

## Trinito
**Менеджер контента**

Специализированный инструмент для управления модами, пакетами текстур и мирами без прямого доступа к файловой системе.

### Вкладки контента

| Вкладка | Тип | Папка назначения |
| :--- | :--- | :--- |
| **Моды** | Файл | `behavior_packs/` |
| **Текстуры** | Файл | `resource_packs/` |
| **Миры** | Папка | `minecraftWorlds/` |

### Состояния
*   **Включено:** Файл сохраняет своё обычное имя и загружается игрой.
*   **Отключено:** Файл переименовывается с расширением `.disabled` и игнорируется игрой.
*   **Интерактивное:** Используйте флажки, чтобы мгновенно включать или выключать контент.
