# Разработка: обзор

Добро пожаловать в экосистему разработки Trinity Projects. Это пространство объединяет знания, инструменты и стандарты, необходимые для участия в разработке наших лаунчеров.

## Проект

В настоящее время наша разработка сосредоточена на растущей экосистеме проектов с открытым исходным кодом:

* **Trinity Launcher:** Наша базовая платформа и платформа управления экземплярами для Minecraft Bedrock.
* **Neko Void:** Дистрибутив Void Linux с `runit`, рабочим столом MATE и предварительно настроенной поддержкой игр. На 100% без systemd.
* **CMUS++:** Сверхлёгкий терминальный музыкальный плеер с управлением с клавиатуры, написанный на C++17.
* **Audio Source:** Используйте устройство Android как USB-микрофон с управлением через TUI и системный трей.

## Архитектура и философия

Мы стремимся создавать модульное, быстрое и безопасное программное обеспечение. Наша архитектура основана на разделении ответственности: **Core** управляет тяжёлыми процессами, а **UI** обеспечивает плавный и современный пользовательский опыт.

Полный стек технологий и разбивку компонентов см. на [странице проекта Trinity Launcher](./projects/trinity-launcher/index.md) и [странице проекта Neko Void](./projects/neko-void/index.md).

## С чего начать?

Если вы новичок в проекте, рекомендуем следовать этому порядку:

1. **Изучите проекты:** Перейдите в раздел [Проекты](./projects/index.md), чтобы понять архитектуру и технические детали каждого проекта.
2. **Выберите свой проект:** У каждого проекта есть собственная домашняя страница с полной документацией — [Trinity Launcher](./projects/trinity-launcher/index.md), [Neko Void](./projects/neko-void/index.md), [CMUS++](./projects/cmuspp/index.md) и [Audio Source](./projects/audiosource/index.md).
