# Конфигурация Trinity Launcher
Настройте Trinity Launcher для оптимального опыта Minecraft Bedrock

## 1. Первоначальная настройка
**Добавьте свою первую версию Minecraft**

Чтобы начать использовать Trinity Launcher, вам нужно импортировать как минимум одну версию Minecraft Bedrock в формате APK.

### Требования к APK
* **Архитектура:** `x86_64` (64-бит)
* **Формат:** файл `.apk`
* **Совместимость:** любая версия Bedrock

::: danger Важно
**Trinity Launcher НЕ предоставляет копии Minecraft Bedrock.** Вы должны получить собственную копию законным способом.
:::

## 2. Управление версиями
**Управление несколькими экземплярами**

Trinity Launcher позволяет управлять несколькими версиями Minecraft Bedrock одновременно.

**Разные варианты опыта**
* Стабильная версия для обычной игры
* Бета-версия для новых функций
* Старые версии для совместимости с модами

**Конкретные конфигурации**
* Профили с разными наборами модов
* Оптимизированные настройки производительности
* Отдельные миры для каждой версии

::: tip 💡 Совет
Чтобы добавить новую версию, выберите **«Извлечь APK»** в интерфейсе Trinity Launcher и укажите загруженный файл.
:::

## 3. Настройка и контент
**Моды, паки и миры**

Управляйте всем своим контентом прямо из интерфейса лаунчера.

**Пакеты текстур**
* Поддержка `.mcpack`
* Живой предпросмотр
* Лёгкое управление

**Моды и аддоны**
* Поддержка `.mcaddon`
* Обработка зависимостей
* Установка в один клик

**Миры**
* Импорт `.mcworld`
* Система резервного копирования
* Лёгкий обмен
