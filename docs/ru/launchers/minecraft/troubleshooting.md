# Журналы и отчёты

При возникновении проблемы с Trinity Launcher или любым из его компонентов предоставление подробного отчёта с журналами крайне важно, чтобы наша команда могла эффективно вам помочь.

## 1. Получение журналов лаунчера

Прежде чем составить отчёт, вам нужно получить журналы, содержащие технические детали об ошибке.

### Как экспортировать журналы через терминал

В настоящее время самый надёжный способ получить журналы — запустить приложение из терминала. Это захватывает вывод в реальном времени, что крайне важно для отладки.

**Для пользователей Flatpak:**
```bash
flatpak run "Package.ID"
```

**Для пользователей Native / AppImage:**
```bash
# AppImage
./TrinityLauncher.AppImage

# Native
trinity-launcher
```

Скопируйте вывод терминала и сохраните его в текстовый файл с именем `trinity-log.txt`.

## 2. Сообщение о проблеме

Получив журналы, выполните следующие шаги, чтобы правильно сообщить о проблеме.

1.  Присоединитесь к нашему **Discord-серверу**.
2.  Перейдите в канал **#help-forum**.
3.  **Создайте новую тему** для своей проблемы.

## 3. Что включить в отчёт

Ваша тема должна содержать следующие детали, чтобы быть рассмотренной. **Пожалуйста, объясните чётко:**

*   **Что произошло:** Чёткое описание ошибки.
*   **Как это произошло:** Пошаговая инструкция по воспроизведению проблемы.
*   **Детали системы:**
    *   ОС и версия (например, Ubuntu 22.04, Arch Linux).
    *   Версия лаунчера.
    *   Компоненты/оборудование (CPU, GPU, RAM) — *Сообщайте только актуальную информацию.*
*   **Предпринятые действия:** Что вы уже пробовали сделать для исправления?

## 4. Рекомендации

::: warning ВАЖНО
**Следуйте закреплённым сообщениям в канале #help-forum.**
:::

Несоблюдение рекомендаций или предоставление неполной информации может привести к тому, что ваш запрос в поддержку будет проигнорирован или закрыт. 

*   Будьте терпеливы и вежливы.
*   Не отправляйте личные сообщения членам команды для получения поддержки.
*   Используйте блоки кода для коротких фрагментов журналов или загружайте файл для длинных журналов.
