# Trinity Launcher: Обзор

Trinity Launcher обеспечивает почти нативный опыт для **Minecraft Bedrock Edition** на Linux. Вместо тяжёлых эмуляторов наше решение использует проекты сообщества, которые переводят системные вызовы Android в нативные инструкции Linux.

### Усилия сообщества
Эта реализация стала возможной благодаря сотрудничеству нескольких инициатив с открытым исходным кодом:
* **mcpelauncher-manifest:** Поддерживает версии игры в актуальном и доступном состоянии.
* **msa:** Обеспечивает безопасную аутентификацию с учётными записями Microsoft.

Интегрируя эти проекты, Trinity Launcher предлагает бесшовный опыт с поддержкой Xbox Live, мультиплеера и текстур высокого разрешения.
