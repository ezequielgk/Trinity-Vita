# Лаунчеры

Trinity Projects создаёт лаунчеры, которые приносят игры без нативной поддержки Linux на рабочий стол Linux.

Каждый лаунчер распространяется как пакет **Flatpak**, оставаясь изолированным от вашей основной системы для безопасного и стабильного использования.

## Доступные лаунчеры

### Minecraft Bedrock
Играйте в **Minecraft Bedrock Edition** на Linux с почти нативным опытом благодаря проектам сообщества `mcpelauncher` и `msa`.

- [Обзор](./minecraft/overview) Как это работает
- [Установка](./minecraft/installation) Установка лаунчера
- [Конфигурация](./minecraft/configuration) Настройка версий и контента
