# Configurazione di Trinity Launcher
Configura Trinity Launcher per un'esperienza Minecraft Bedrock ottimale

## 1. Configurazione iniziale
**Aggiungi la tua prima versione di Minecraft**

Per iniziare a usare Trinity Launcher, devi importare almeno una versione di Minecraft Bedrock in formato APK.

### Requisiti APK
* **Architettura:** `x86_64` (64 bit)
* **Formato:** file `.apk`
* **Compatibilità:** qualsiasi versione Bedrock

::: danger Importante
**Trinity Launcher NON fornisce copie di Minecraft Bedrock.** Devi procurarti la tua copia con mezzi legali.
:::

## 2. Gestione delle versioni
**Gestisci più istanze**

Trinity Launcher ti consente di gestire più versioni di Minecraft Bedrock contemporaneamente.

**Esperienze diverse**
* Versione stabile per il gioco normale
* Versione beta per nuove funzionalità
* Versioni più vecchie per la compatibilità con le mod

**Configurazioni specifiche**
* Profili con diversi set di mod
* Impostazioni prestazionali ottimizzate
* Mondi separati per versione

::: tip 💡 Suggerimento
Per aggiungere una nuova versione, seleziona **"Estrai APK"** dall'interfaccia di Trinity Launcher e scegli il file scaricato.
:::

## 3. Personalizzazione e contenuti
**Mod, pack e mondi**

Gestisci tutti i tuoi contenuti direttamente dall'interfaccia del launcher.

**Pacchetti di texture**
* Supporta `.mcpack`
* Anteprima dal vivo
* Gestione facile

**Mod e Addon**
* Supporta `.mcaddon`
* Gestione delle dipendenze
* Installazione in un clic

**Mondi**
* Importa `.mcworld`
* Sistema di backup
* Condivisione facile
