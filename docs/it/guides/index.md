# Benvenuto in Trinity

Trinity è un ecosistema open source di progetti Linux: un launcher di giochi, una distribuzione Void Linux leggera e altro ancora.

## Progetti

- **Trinity Launcher:** Gestisce il tuo gioco, le istanze e gli account. Costruito con Qt6 e distribuito tramite Flatpak.
- **Neko Void:** Una distribuzione **Void Linux** con `runit`, il desktop MATE e supporto gaming preconfigurato. 100% senza systemd.
- **CMUS++:** Un lettore musicale per terminale.
- **Audio Source:** Usa il tuo dispositivo Android come microfono USB.
- **BedrockOnLinux:** Esegui Minecraft Bedrock per Windows (edizione GDK) su Linux con identità nativa Microsoft/Xbox.
- **GenovaLauncher:** Un launcher grafico moderno per Minecraft: Bedrock Edition su Linux.
