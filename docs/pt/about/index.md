# Introdução

Bem-vindo(a) ao **Trinity Projects**, um ecossistema de código aberto dedicado a quebrar as barreiras entre os sistemas operacionais e os usuários finais. Criamos ferramentas que tornam a acessibilidade do Linux uma realidade para jogadores e criadores.

## Quem Somos

Trinity Projects é uma iniciativa orientada pela comunidade, focada em criar software de alta qualidade e fácil utilização para o ecossistema Linux. Acreditamos que tecnologia poderosa não precisa ser complicada. Nossa equipe é formada por desenvolvedores apaixonados, designers e entusiastas de código aberto que trabalham juntos para melhorar a experiência de desktop no Linux.

## O Que Fazemos

Desenvolvemos lançadores e ferramentas intuitivas que simplificam tarefas complexas.

### Projetos Principais

*   **Trinity Launcher:** Nosso lançador moderno para **Minecraft Bedrock Edition** no Linux. Saiba mais em [Projetos > Trinity Launcher](/pt/dev/projects/trinity-launcher/).

## Por Que "Trinity"?

O nome representa os três pilares fundamentais da nossa filosofia:
1.  **Desempenho:** Software que respeita o seu hardware.
2.  **Simplicidade:** Interfaces que qualquer pessoa pode usar.
3.  **Liberdade:** Código aberto, transparente e centrado no usuário.
