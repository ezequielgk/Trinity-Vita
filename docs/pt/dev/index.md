# Desenvolvimento: Resumo

Bem-vindo(a) ao ecossistema de desenvolvimento do Trinity Projects. Este espaço centraliza o conhecimento, as ferramentas e os padrões necessários para contribuir com nossos lançadores.

## O Projeto

Nosso desenvolvimento atualmente se concentra em um ecossistema crescente de projetos de código aberto:

* **Trinity Launcher:** Nosso mecanismo base e plataforma de gerenciamento de instâncias para Minecraft Bedrock.
* **Neko Void:** Uma distribuição Void Linux com `runit`, o desktop MATE e suporte a jogos pré-configurado. 100% livre de systemd.
* **CMUS++:** Um player de música para terminal ultraleve e controlado por teclado, escrito em C++17.
* **Audio Source:** Use seu dispositivo Android como microfone USB com TUI e controle pela bandeja do sistema.

## Arquitetura e Filosofia

Buscamos criar software modular, rápido e seguro. Nossa arquitetura é baseada na separação de responsabilidades: o **Core** gerencia processos pesados, enquanto a **UI** oferece uma experiência de usuário fluida e moderna.

Para ver a pilha tecnológica completa e o detalhamento dos componentes, consulte a [página do projeto Trinity Launcher](./projects/trinity-launcher/index.md) e a [página do projeto Neko Void](./projects/neko-void/index.md).

## Por onde começar?

Se você é novo no projeto, recomendamos seguir esta ordem:

1. **Explore os Projetos:** Vá para a seção [Projetos](./projects/index.md) para entender a arquitetura e os detalhes técnicos de cada projeto.
2. **Escolha seu projeto:** Cada projeto tem sua própria página inicial com documentação completa — [Trinity Launcher](./projects/trinity-launcher/index.md), [Neko Void](./projects/neko-void/index.md), [CMUS++](./projects/cmuspp/index.md) e [Audio Source](./projects/audiosource/index.md).
