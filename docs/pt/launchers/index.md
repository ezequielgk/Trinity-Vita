# Lançadores

O Trinity Projects cria lançadores que levam jogos sem suporte nativo ao Linux para o desktop Linux.

Cada lançador é distribuído como um pacote **Flatpak**, mantendo-o isolado do seu sistema principal para uma experiência segura e estável.

## Lançadores Disponíveis

### Minecraft Bedrock
Jogue **Minecraft Bedrock Edition** no Linux com uma experiência semelhante à nativa, potencializada pelos projetos da comunidade `mcpelauncher` e `msa`.
