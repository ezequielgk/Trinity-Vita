# Lançadores

O Trinity Projects cria lançadores que levam jogos sem suporte nativo ao Linux para o desktop Linux.

Cada lançador é distribuído como um pacote **Flatpak**, mantendo-o isolado do seu sistema principal para uma experiência segura e estável.

## Lançadores Disponíveis

### Minecraft Bedrock
Jogue **Minecraft Bedrock Edition** no Linux com uma experiência semelhante à nativa, potencializada pelos projetos da comunidade `mcpelauncher` e `msa`.

- [Visão geral](./minecraft/overview) Como funciona
- [Instalação](./minecraft/installation) Instale o lançador
- [Configuração](./minecraft/configuration) Configure versões e conteúdo

### BedrockOnLinux
Execute o **Minecraft Bedrock para Windows (edição GDK)** no Linux com identidade nativa da Microsoft/Xbox, multijogador, amigos e Realms.

- [Visão geral](./bedrock-on-linux/) Execute a edição GDK do Windows com identidade nativa do Xbox
- [Instalação](./bedrock-on-linux/#instalação) AppImage, .deb, .pyz e Flatpak

### GenovaLauncher
Um lançador gráfico moderno para **Minecraft: Bedrock Edition** no Linux, construído com PySide6 (Qt6) e baseado no mcpelauncher.

- [Visão geral](./genova-launcher/) Lançador moderno com PySide6 para a Bedrock Edition
