# Configuração do Trinity Launcher
Configure o Trinity Launcher para uma experiência ideal com o Minecraft Bedrock

## 1. Configuração Inicial
**Adicione sua primeira versão do Minecraft**

Para começar a usar o Trinity Launcher, você precisa importar pelo menos uma versão do Minecraft Bedrock no formato APK.

### Requisitos do APK
* **Arquitetura:** `x86_64` (64 bits)
* **Formato:** arquivo `.apk`
* **Compatibilidade:** qualquer versão do Bedrock

::: danger Importante
**O Trinity Launcher NÃO fornece cópias do Minecraft Bedrock.** Você deve obter sua própria cópia por meios legais.
:::

## 2. Gerenciamento de Versões
**Gerencie várias instâncias**

O Trinity Launcher permite gerenciar várias versões do Minecraft Bedrock simultaneamente.

**Experiências Diferentes**
* Versão estável para o jogo normal
* Versão beta para novos recursos
* Versões antigas para compatibilidade com mods

**Configurações Específicas**
* Perfis com diferentes conjuntos de mods
* Configurações de desempenho otimizadas
* Mundos separados por versão

::: tip 💡 Dica
Para adicionar uma nova versão, selecione **"Extrair APK"** na interface do Trinity Launcher e selecione seu arquivo baixado.
:::

## 3. Personalização e Conteúdo
**Mods, packs e mundos**

Gerencie todo o seu conteúdo diretamente pela interface do lançador.

**Pacotes de Textura**
* Suporta `.mcpack`
* Visualização ao vivo
* Gerenciamento fácil

**Mods e Addons**
* Suporta `.mcaddon`
* Tratamento de dependências
* Instalação com um clique

**Mundos**
* Importar `.mcworld`
* Sistema de backup
* Compartilhamento fácil
