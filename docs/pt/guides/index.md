# Bem-vindo(a) à Trinity

Trinity é um ecossistema de código aberto de projetos Linux: um lançador de jogos, uma distribuição Void Linux leve e muito mais.

## Projetos

- **Trinity Launcher:** Gerencia seu jogo, instâncias e contas. Construído com Qt6 e distribuído via Flatpak.
- **Neko Void:** Uma distribuição **Void Linux** com `runit`, o desktop MATE e suporte a jogos pré-configurado. 100% livre de systemd.
- **CMUS++:** Um player de música para terminal.
- **Audio Source:** Use seu dispositivo Android como microfone USB.
