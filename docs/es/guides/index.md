# Bienvenido a Trinity

Trinity es un ecosistema de código abierto con proyectos para Linux: un lanzador de juegos, una distribución ligera de Void Linux y más.

## Proyectos

- **Trinity Launcher:** Gestiona tu juego, instancias y cuentas. Construido con Qt6 y distribuido vía Flatpak.
- **Neko Void:** Distribución de **Void Linux** con `runit`, escritorio MATE y gaming preconfigurado. 100% libre de systemd.
- **CMUS++:** Reproductor de música para terminal.
- **Audio Source:** Usa tu Android como micrófono USB.
